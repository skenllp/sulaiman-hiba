# Sulaiman & Hiba – Nikah Invitation

Static site (HTML/CSS/JS). Open `index.html` or deploy the folder to any static host.

## Before publishing (edit `script.js` / `index.html`)
1. `NIKAH_START` – currently an approximate 4:00 PM IST. Replace with the confirmed time, e.g. `"2027-01-02T16:45:00+05:30"`.
2. Music: `assets/audio.mp3` (55 s clip, loops) plays after the envelope tap; a small speaker button (bottom-right) pauses it.


Open Graph URLs are set to https://sulaiman-hiba.vercel.app/.
